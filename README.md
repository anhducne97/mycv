# Phạm Anh Đức (Nick Pham)

Personal profile page (English / Tiếng Việt) with a downloadable one-page CV.

- `index.html`: the profile page. Add `#vi` or `#en` to the URL to open it in that language.
- `cv/`: CV as A4 PDF, English and Vietnamese.
- `make_cv.py`: regenerates the CV PDFs (needs Playwright, Chrome and the `@fontsource` packages `be-vietnam-pro`, `newsreader`, `ibm-plex-mono` in `node_modules`).
